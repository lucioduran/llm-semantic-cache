# Evaluation method

The frozen corpus has four fictional entities, each with twelve requests: initial storage quota, exact repeat, paraphrase, backup quota, changed date, elevated permissions, another user, new version, version invalidation plus updated value, repeat, user deletion plus updated value, repeat. All data is original and contains no personal records. Expected labels never enter cache decisions. Numeric source facts enter the model prompt as context.

The run uses one cache per policy and actual independent model generation on every miss. Exact policy stores no embeddings. Semantic policies attempt exact lookup first, then compute a real MiniLM vector on a miss and scan the eligible scope. Mean pooling uses the attention mask and L2 normalization. Generation uses FLAN-T5-small with greedy decoding, a 384-token input ceiling, and at most 32 output tokens. Overflow raises an error rather than silently truncating. Threshold 0.90 was selected before the run, without tuning on the fixture.

The unsafe diagnostic deliberately maps every request to one shared scope, including version and user. Thus its invalidation selectors no longer match its entries. It demonstrates the combined consequences of throwing away boundaries, including stale answers; it is not an isolated ablation of just cosine search. Its speed is never presented as a valid optimization.

Correct-hit count requires equality of the original source request's scope, intended fact, and expected value. Incorrect-hit count includes any failed equality. Correct-hit rate and incorrect-hit rate divide by all 48 requests, while incorrect fraction of hits divides by hits only. Answer exact match strips whitespace and one optional ` GB` suffix. Hit correctness does not imply generated answer correctness.

Net saved seconds = uncached total request seconds minus policy total request seconds. Net saved fraction divides that difference by uncached total. Total request time includes invalidation, ticket acquisition, exact lookup, optional embedding and semantic lookup, miss generation, insertion, and light bookkeeping. Component timers are nested within the total. Cache construction, model loading, one embedding warmup, one generation warmup, evidence serialization, and model hashing are excluded. Every policy is run sequentially in the fixed order none, exact, semantic, unsafe diagnostic. There are no repetitions or confidence intervals. Thermal state and order effects can affect the result.

The reference experiment ran on October 21, 2026 using the shared exclusive benchmark wrapper and four CPU threads. It reused pinned model files read-only from a prior local project, with a new project-specific Python environment. No paid resource or hosted inference was used. Dependencies and model fingerprints are in the report. No GPU was used. Monetary savings are not estimated.

Replay reconstructs cache decisions from recorded vectors and generated strings, checks origin labels and prompts, recomputes answer scores and aggregates, and validates trace and input file hashes. It does not rerun neural inference, validate wall-clock authenticity, or independently establish model provenance. Unit tests use test doubles; the report is real neural evidence. Cross-platform CI verifies portable cache behavior and replay only.
